# Ghost Ping Logger

Find mentions and replies that were deleted or edited away and get alerted.

- Alert when someone pings you and deletes or edits the ping away.
- Ghost ping history with search and filters.
- Highlighted ghost pings in chat.

Requires **Adv. Message Logger**: ghost pings are read from its journal.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of Ghost Ping Logger. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
